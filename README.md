## 🚀 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DuddeJaitej/Jaitej-Portfolio.git
   cd Jaitej-Portfolio
   ```

2. **Launch with any local HTTP server:**
   - **Using Python:**
     ```bash
     python -m http.server 8000
     ```
   - **Using VS Code Live Server:**
     Right-click `index.html` or `Home/Home.html` and click **"Open with Live Server"**.
   - **Using Node `npx serve`:**
     ```bash
     npx serve .
     ```

3. **Open in your browser:**
   ```text
   http://localhost:8000/
   ```

## 🌐 Deploy to Vercel

This repository is pre-configured with `vercel.json` for **zero-configuration deployment**:

1. Go to **[vercel.com/new](https://vercel.com/new)**.
2. Select repository **`Jaitej-Portfolio`**.
3. Click **Deploy** (no build settings required).
4. Your site will be live instantly!
